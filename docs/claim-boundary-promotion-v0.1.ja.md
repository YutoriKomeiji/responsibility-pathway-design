# RPD Claim Boundary Promotion v0.1（主張境界の昇格）

RPDでは公開上の主張をevidence-governed stateとして扱います。現在のresearch non-claimを自動的に永久免責とはみなしません。

RPDは次を分離します。

1. 宣言したreview、empirical、comparative、operational evidenceが得られれば前進できる **evidence-limited research boundary**
2. design-translation framework単体では越えるべきでない **permanent responsibility boundary**

## Current Evidence Boundary

RPD v0.1は **provisional, reviewable research baseline** です。現在のevidenceが支えるのは、internal coherence、inspectability、文書化されたtransformation step、明示的なassurance / operational-governance interface、D/I/X/O/V verification vocabularyです。

Broad external validity、comparative superiority、一般的empirical effectiveness、standardization、certification、production / operational authorizationはまだ成立していません。

## Promotion Criteria

| 現在の境界 | 境界を前進させるevidence |
|---|---|
| internal coherenceまで | 独立structured review、issue/counterexample解消、cross-document traceability、再現可能なworked-case review |
| empirical validationが限定的 | predeclared empirical protocol、coded case corpus、adjudication、study result、negative/counterexample case、可能な範囲でreplication |
| comparative effectiveness未主張 | baseline / alternative design method、comparison criteria、matched caseまたはcontrolled evaluation、failure analysis |
| operational validationが限定的 | D/I/X/O/V vocabularyに基づくexercise / operational evidence。intervention timing、returnability、contestability、recovery、residual stewardshipを含む |
| broader contextual validity未主張 | multi-domain / multi-context study、affected-party / institutional review、boundary-condition analysis、失敗時のtheory revision |
| standardization / certification未主張 | repository外の独立governance / standards process。RPD artifactだけではofficial standardやcertification schemeへ自己昇格できない |

Worked example、design audit、downstream implementationが成功しても、それだけでbroad empirical validityへ自動昇格しません。

## Permanent Responsibility Boundaries

- RPDはlaw、policy、ethics、standard、affected-party mandateを創設・自動解釈・最終確定しません。
- 法的責任を確定したり、最終責任をAIへ移転しません。
- systems safety、human factors、requirements engineering、assurance、incident response、institutional governanceを代替しません。
- documentation、logging、technical rollbackだけを責任回復の完了と扱いません。
- assurance recordを自己認証的certificationにしません。
- operational authorization、continuation、suspension、redesign、retirement、remedy、residual-impact stewardshipの最終権限は責任主体である人間・制度に残ります。

これらは未完成research milestoneではなく責任境界です。

## Evidence Owner / Promotion State

RPD research/designはdefinition、transformation logic、pattern/evaluation record、falsification criteria、宣言したdesign-level evidenceを担当します。RPE/runtime/operationからimplementation、exercise、operational evidenceを受け取れますが、明示的reviewなしにRPD claimへ自動昇格させません。Broader validationにはexternal researcher、affected party、practitioner、institutionが必要です。Legal、certification、operational authorityは外部に残ります。

可能な範囲でevidence依存境界は `evidence_collecting` / `review_ready` / `promoted`、恒久境界は `permanently_out_of_scope` を使用します。
